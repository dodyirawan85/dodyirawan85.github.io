Known Issues
  • Bootloop on 4GB variant (fix: mount system, and delete bootanimation.zip in /system/product/media)
  • Broken ext4 userdata on 4/6 GB ram variant [8GB variant works fine]
  • Auto brightness not working in favor of deep sleep

Prerequisites

  1. Unlocked Bootloader
  2. Custom recovery installed

Flashing Instruction

  1. Wipe data, system, cache, vendor and dalvik
  2. Install Rom
  3. Install Gapps (Optional)
  4. Install Magisk (Optional)
  5. Format Data To F2FS (BACKUP FIRST !)
  6. Reboot
